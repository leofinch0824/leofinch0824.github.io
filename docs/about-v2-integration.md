## 新原型结构（自上而下）

1. **卷首 about-hero 双栏**：左 = 眉标（锈红）+ h1「拍照片的人，也写代码。」
   + lead 暗房句 + **身份矩阵**；右 = **双卡叠压**；下方**处境工具条**。
2. **为什么写**：prose（题解叙事）+ pullquote（署名「— 写在第十篇之后」）。
3. **自述海报**（新板块）：眉标「一些零碎的」+ 5 条巨型衬线碎片（26–45px/600）。
4. **制作说明 credits**：相纸卡片容器 + 两列网格（credit-key/val），内容已按
   现实更新（KaTeX/Shiki 已接入、复制按钮交互、占位图说明）。
5. **联系 cta**：h2 + lead「我更新不勤，但每封都会回」+ 单写信按钮 +
   **findme 单行链接条**（找得到我：GitHub/Bluesky/RSS/mailto）。

  在做 = 拾光集；在看 = 电影（可列近年最爱？）；在手边 = 哑铃/咖啡/笔记本？
- poster-list 五条需重写。「网上叫 leofinch，熟人叫别的」「想清楚了才写，
  写完就发」可保留；「走错路，才到过一些好地方」通用可留；器材/猫两条需替换
  为健身/电影向真实碎片。
