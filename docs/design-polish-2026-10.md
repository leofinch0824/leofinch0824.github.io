# 设计精修 · 2026-10-04（第 1 轮）

作者提出的 5 项风格精修。这批改动**全部是所有者对原型基准的有意覆写**：
`reference/prototype/` 保持只读原样，本文件即为偏差的授权记录与验收依据。

## 逐项分析

### 1. 顶栏副标：`Shiguang` → `Time Travel`

- **位置**：`src/components/Header.astro:15`（`.logo-sub`）。
- **分析**：副标是等宽小字（`text-transform:uppercase`），写 `Time Travel` 即显示 `TIME TRAVEL`。纯文案替换，零样式改动；760px 以下随既有规则隐藏。英文两词符合 DESIGN「标签只写西文与数字」。
- **方案**：改字符串，一处。

### 2. 首页去掉「卷首 · 第 01 辑」眉标

- **位置**：`src/pages/index.astro`（`.eyebrow.eyebrow-lead`）。
- **分析**：该眉标是全站两处 `--accent` 用法之一（DESIGN「每屏至多两次」是上限不是配额），删去后首页强调色只剩订阅主按钮 + 年份展开圆点（状态指示），更克制。About 页的「关于 · 第 01 版」不受影响。
- **方案**：删整行；h1 成为首元素，排版无依赖。

### 3. 首页标语换为电影语录

- **位置**：`src/pages/index.astro`（`.lead`）。
- **要求**：符合「用影像记录生活、用文字表达生活」的电影/名人语录，先搜索后定。
- **选定**（出处已核实：新浪微博 #每人夜话#、豆瓣《一一》影评）：
  > 电影发明以后，人类的生命比起以前至少延长了三倍。—— 杨德昌《一一》（片中胖子台词）
- **分析**：与副标 Time Travel、「按年份展开」的时间线隐喻同构——翻相册=重历时光=延长生命；电影语录且中文影史名句，气质契合「文字也是一种影像记录」的北星句（北星句仍保留在 About 页导语中，不在首页重复）。
- **落选备选**：苏珊·桑塔格「收集照片就是收集世界」（《论摄影》，偏摄影单侧）。
- **方案**：`.lead` 文案替换为引文 + 破折号署名，样式不动。

### 4. 「记忆墙」区块标题 → 「最近回忆录」；删提示小字

- **位置**：`src/components/MemoryWall.astro:16,19`。
- **分析**：顶栏导航词「记忆墙」保持不变（用户仅指区块标题）；提示行 `.wall-hint`（「墙上默认摊开最近的两年……」）整行删除，其唯一作用是解释交互，状态行（第 5 项重写后）已能承担。组件内 `<style>` 仅含 `.wall-hint` 一条布局规则，随之删除。
- **方案**：h2 换文案；删 hint 行与空样式块。

### 5. 年份轨迹：措辞重写 + 年份格居中

- **位置**：`src/components/YearTrail.astro`（眉标/标题/状态行服务端文案）、`src/components/MemoryWall.astro`（状态行客户端文案，两处必须同步）、`src/styles/global.css`（`.year-cell`）。
- **分析**：
  - 「生活轨迹」→「时间线」，「摊开某一年」→「按年份展开」——直白易懂；
  - 状态行（aria-live）现为「已摊开 2026、2024；还有 N 张按年份收着。」——重写为「翻相册」隐喻：`已翻开 2026、2024；还有 N 张沉在相册深处，点一下年份就能取回。` / 全开时 `整本相册都翻开了，N 张回忆都在墙上。`（无 JS 的服务端初值与脚本刷新文案逐字一致）；
  - `.year-cell` 现为 `text-align:left; padding:24px 20px 24px 0`（贴左沿）→ 居中：`text-align:center; padding:24px 20px`；600px 断点原有的 `padding-right:0` 是为贴左布局补偿的，居中后必须移除，否则移动端内容会偏左；展开态圆点（`.year-num::after`）为行内元素，居中不受影响。
- **方案**：文案三处 + `.year-cell` 两条 CSS（主规则与 600px 断点）。

## 验收

- `npm run build` + `npm run check` 全绿；
- 首页 1440 截图目验：副标 TIME TRAVEL、无卷首眉标、新语录、最近回忆录、年份格内容居中（含 390 抽查）；
- 其余页面不受影响（改动全部收敛在首页与顶栏）。

# 设计精修 · 2026-10-04（第 2 轮）

2 项，全部收敛在首页卷首。同第 1 轮：**所有者对原型基准的有意覆写**，本文件为偏差授权记录。

## 逐项分析

### 6. 卷首大标题 → 格言式站标（换文案 + 缩字号）

- **位置**：`src/pages/index.astro`（`.intro h1`）、`src/styles/global.css:274`（`.intro h1` 覆写）。
- **要求**：把「把日子摊开，像一叠刚冲出来的照片。」换成更合适的标题，字号从大标题档降为「格言标语类」的合适大小。
- **分析**：
  - 全局 `h1` 规格是 `--fs-h1`（clamp 38–64px）、字重 600、行高 1.1、字距 -0.015em——那是文章页 `article-head h1` 的大标题规格；格言档应该小而克制，且 64px 档的紧行高/负字距照搬到小字号会把汉字挤在一起；
  - 档位选用现有令牌 `--fs-h3`（21px），不造新值；覆写收敛在 `.intro h1` 作用域，全局 `h1` 与文章页大标题不动；
  - 字重 600→500（格言不必用标题的重锤）、行高 1.1→1.66（中文正文舒展）、字距归 0；衬线 `--font-display` 保留，标语仍有印刷感；
  - 21px 的 h1 会小于区块 h2（24–32px）——**有意倒挂**：卷首是格言不是标题，视觉主角让给记忆墙；
  - 新文案选定：`用影像记录生活，用文字表达生活。`——出自所有者自述的站点方向（第 1 轮 #3 的选语标准即由此而来），作站标名正言顺，非引用故无需出处核实。15 字 @21px 一行可容（390px 屏亦然），不再需要 `<br class="brk" />`（断点规则保留，About 页仍在用）。
- **方案**：h1 文案一行替换；`.intro h1` 覆写为 `font-size:var(--fs-h3); font-weight:500; line-height:1.66; letter-spacing:0; margin-bottom:var(--gap-lg)`（间距从 `--gap-md` 提升以衔接被删的 lead 行；13em 限宽与 600px 断点 `max-width:none` 补偿行一并删除）。

### 7. 删除《一一》语录行

- **位置**：`src/pages/index.astro`（`.intro .lead` 整段及其出处注释）。
- **分析**：第 1 轮 #3 引入的引文，本轮所有者决定整行去掉——卷首只留格言站标 + intro-meta 元信息条，更干净。`.lead` 类在 SubscribeCta / BlogPost / about / blog 归档四处仍在用，只删首页实例；global.css 的 `.intro .lead` 作用域规则随之删除，`.lead` 全局规则保留。
- **方案**：删段落 + 注释；删 `.intro .lead` 一条 CSS。

### 8. 归档页卷首：删两行自述式说明文案

- **位置**：`src/pages/blog/index.astro:59-60`（`.intro h1` + `.lead`）。
- **要求**：「{total} 张相纸，按年份摞好。」与「相册从上往下翻，最新的在最上面。每一行都是一次记录，点开就是那篇文章。」是页面在解释自己（所有者判定为开发期备注性质），直接删掉。
- **分析**：删后卷首 = 眉标「归档 · YYYY — YYYY」+ 年份胶囊直接进相册，`.year-jump` 自带 `margin-top:var(--gap-lg)` 间距自足。但页面不能没有 `h1`（语义/无障碍）：眉标行升为 `<h1 class="eyebrow">`。**级联陷阱**：`.eyebrow` 能盖过全局 `h1`（元素选择器），但盖不过本轮 #6 新加的 `.intro h1` 格言覆写——同为单类特异性、后者定义在后，实测把眉标打成 21px/500/字距 0。修复：格言覆写改 `.intro h1:not(.eyebrow)`，归档页 h1 全套规格走 `.eyebrow`（mono 11.5px/400/0.13em），视觉与改前 `<p class="eyebrow">` 完全一致；`.eyebrow` 补 `font-weight:400` 防住 h1 默认粗体（其余 6 处 `.eyebrow` 均为 `p`，默认即 400，无副作用）。
- **方案**：删两行；`<p class="eyebrow">` → `<h1 class="eyebrow">`（仅归档页；About 页眉标维持 p，其上有自己的 h1）；`global.css` `.intro h1` → `.intro h1:not(.eyebrow)`、`.eyebrow` 补 `font-weight:400`。

## 验收（第 2 轮）

- `npm run build` + `npm run check` 全绿；
- 首页 DOM 断言：h1 文案 =「用影像记录生活，用文字表达生活。」、computed `font-size`=21px、`.intro .lead` 不存在、intro-meta 三条仍在；
- 归档页 DOM 断言：无「相纸」「相册从上往下翻」文案、卷首 h1 = 眉标文案「归档 · YYYY — YYYY」、year-jump 仍在；
- 截图目验（1440/390）：标语与眉标规格、卷首干净无溢出。

# 设计精修 · 2026-10-04（第 3 轮）

2 项，订阅信息收口到页脚 + 清理开发期遗留入口。

## 逐项分析

### 9. 订阅大段删除，内容整合进页脚「订阅」栏

- **位置**：`src/components/SubscribeCta.astro`（整件删除；使用者 index.astro 与 YearAlbum.astro）、`src/components/Footer.astro`（订阅栏）、`src/styles/global.css`（footer 段）。
- **要求**：首页/归档页的大段「不想错过下一张？」引导删除；内容整合到底部栏「订阅」标题下，订阅部分用合适的风格颜色做体现。
- **分析**：页内订阅大段（h2 + lead + 双按钮）在每页重复且占一屏段落，订阅是次级动作，归宿是页脚；About 页「找到我」的联系 CTA 不动（那是联系不是订阅）。页脚「订阅」栏原只有两个裸链接——整合后成为一个**浅墨底面板**（`--fg-soft` 底 + `--radius` 圆角）：一句精简文案（承原 lead 的「送到阅读器/没有推送/没有算法」）+「订阅 RSS →」强调链接（`--fg` 色 + 500 字重 + 既有 `→` 箭头语言）+「邮件订阅 · 未开通」muted 占位（无 href 锚点模式不变）。颜色全走令牌，暗色下浅墨叠暗底自动成立。
- **方案**：删组件与两处引用（`.cta` 样式保留——About 的找到我区仍在用）；Footer 订阅栏改 `.foot-sub` 面板；global.css footer 段加 `.foot-sub/.sub-note/.sub-rss` 三条（颜色仅令牌）。

### 10. 页脚「走一走」删「文章样本」

- **位置**：`src/components/Footer.astro`。
- **分析**：「文章样本」（链最新一篇）是开发阶段给评审看真实文章渲染的入口，正式语义下与「记忆墙/归档」重复（最新一篇永远在归档首行）。删除后走一走剩 记忆墙/归档/关于 三链，frontmatter 的 `getCollection`/`latest` 计算随之消失，页脚回到纯静态导航。
- **方案**：删链接与条件块，frontmatter 精简。

## 验收（第 3 轮）

- `npm run build` + `npm run check` 全绿；
- DOM 断言：全站无「不想错过下一张」；页脚订阅面板（文案 + RSS 强调 + 邮件占位）存在；走一走无「文章样本」；About「找到我」区不受影响；
- 截图目验：页脚亮/暗两档，面板观感与整体协调。
